# Sistema de Cafetería

## 1. Descripción del proyecto

En este proyecto desarrollé un sistema básico para una cafetería utilizando Python. El programa permite registrar pedidos, calcular el total de las compras y consultar las ventas acumuladas durante el día.

## 2. Objetivo

Mi objetivo fue facilitar el registro de pedidos y automatizar los cálculos de los precios, descuentos e IVA para obtener el total que debe pagar cada cliente.

## 3. Funcionalidades

El sistema permite:
- Registrar pedidos de café, sándwiches y jugos.
- Calcular el subtotal y el total a pagar.
- Aplicar un descuento del 10 % a estudiantes en compras de $150.00 o más.
- Calcular el IVA del 16 %.
- Consultar las ventas acumuladas.
- Validar las cantidades ingresadas.

## 4. Tecnologías utilizadas

- Python para desarrollar el programa.
- PSeInt para elaborar el pseudocódigo y el diagrama de flujo.
- Jupyter Notebook para realizar los ejercicios de práctica.
- Visual Studio Code para editar y ejecutar el código.
- GitHub para guardar y organizar los archivos del proyecto.

## 6. Ejemplo de funcionamiento

En una compra de $195.00 realizada por un estudiante, el sistema calcula un descuento de $19.50, un IVA de $28.08 y un total de $203.58.
